# Langbaan Invest

เว็บภาษาไทยสำหรับค้นหาและติดตามแหล่งอ้างอิงการลงทุน 36 รายการในหมวด A–G ตามรายการที่กำหนด ใช้ Next.js, TypeScript และ Tailwind CSS

## พัฒนา

ใช้ Node.js 24 และ npm 11

```sh
npm ci --cache /tmp/langbaan-npm
npm run dev
```

## ตรวจสอบและรัน production

```sh
npm run build
npm run typecheck
npm start
```

ค้นหาด้วยชื่อ เว็บไซต์ หรือหมวดหมู่ กดดาวเพื่อบันทึกและดูรายการที่บันทึกไว้ รายการและโหมดมืดเก็บใน localStorage ของเบราว์เซอร์ โดยไม่ต้องมีบัญชีหรือ API key

รายการเป็นลิงก์ต้นทาง ไม่ใช่ข่าวสด ไม่ได้ยืนยันการเข้าถึงทุกเว็บไซต์ และยังไม่มีการดึงหรือสรุปเนื้อหาอัตโนมัติ บางแหล่งต้องสมัครสมาชิก หมวด G ระบุว่าต้องตรวจการเข้าถึง ส่วน Investor Relations รอ watchlist และ URL ทางการที่ตรวจสอบแล้ว

ขั้นต่อไปสำหรับระบบข่าวสด: เลือก RSS/API ที่อนุญาตการนำเนื้อหามาใช้ แล้วเพิ่มเวลาเผยแพร่ แหล่งที่มา และหน้าข่าว โดยไม่คัดลอกบทความเต็มโดยไม่มีสิทธิ์

## ข่าวที่อ่านภายในเว็บ

เพิ่มประกาศย่อทางการจาก BLS: CPI, Employment Situation และ PPI โดยตรวจเงื่อนไข https://www.bls.gov/bls/linksite.htm แล้ว: ข้อความ BLS เป็นสาธารณสมบัติ ยกเว้นภาพบางประเภท และไม่ใช้ตราหน่วยงาน

หน้าแรกดึง `/api/news` และเปิดประกาศใน `/news/[id]` เนื้อหาประกาศเป็นภาษาอังกฤษ พร้อมคำอธิบายหัวข้อภาษาไทยที่เว็บจัดทำเอง ไม่ใช่บทความเต็มหรือคำแปลอัตโนมัติ

ระบบอ่าน Atom จาก `https://www.bls.gov/feed/{cpi,empsit,ppi}.rss` ฝั่ง server และ cache หนึ่งชั่วโมงเมื่อมีการเข้าใช้งาน ไม่ใช่ scheduled cron ใช้ HTTPS และ proxy จาก environment ตามที่มี หากฟีดล้มเหลว จะแสดง snapshot ที่เก็บใน `data/bls-snapshot.json` พร้อมข้อความระบุเวลาและหมวดที่ใช้ข้อมูลสำรอง ไม่แสดงว่าเป็นข้อมูลสด

BEA, Federal Reserve และสำนักข่าวเอกชนยังไม่เชื่อมต่อ เพราะการเข้าถึงหรือเงื่อนไขการนำมาใช้ยังตรวจไม่ครบ

## คำแปลไทย

ประกาศ BLS ใน snapshot จำนวน 36 รายการมีคำแปลไทยที่จัดทำด้วย AI ของ Langbaan Invest ใน `data/bls-th.json` พร้อมวันที่แปลและข้อความต้นฉบับ หน้าแรกเลือกไทย/English ได้ และหน้าประกาศเปิดอ่านต้นฉบับอังกฤษเทียบได้ ตัวเลขในหัวข้อและเนื้อหาคำแปลตรวจเทียบต้นฉบับแล้ว

คำแปลใช้ได้ต่อเมื่อ id และข้อความต้นฉบับยังตรงกันหลังปรับช่องว่าง หาก BLS แก้ไขข้อความ หรือมีข่าวใหม่ที่ยังไม่ได้แปล จะแสดงอังกฤษพร้อมสถานะยังไม่มีคำแปล ไม่ใช้คำแปลเก่ากับข่าวฉบับแก้ไข และไม่อ้างว่าเป็นคำแปลทางการ ไม่มีบริการแปลข่าวใหม่อัตโนมัติในขณะนี้

## ข่าวเพิ่มเติมและสินทรัพย์ที่เกี่ยวข้อง

เชื่อม BLS อีกสี่ฟีดที่ตรวจอ่านจริง: JOLTS (`jolts.rss`), Employment Cost Index (`eci.rss`), Productivity and Costs (`prod2.rss`), Import/Export Prices (`ximpim.rss`) รวมเจ็ดฟีดและ snapshot 84 ประกาศ รายการใหม่ 48 ประกาศยังไม่มีคำแปลไทย ไม่ใช่ข่าวบริษัทหรือราคาตลาดสด

สินทรัพย์ตัวอย่าง: SPY, QQQ, TLT, GLD, UUP, XLI และ XLY กดจากการ์ดข่าวหรือหน้าข่าวไป `/assets/[symbol]` เพื่ออ่านรายละเอียด เหตุผลเชิงเศรษฐกิจ และประกาศที่เกี่ยวข้อง ความเชื่อมโยงกำหนดตามหัวข้อใน `lib/assets.ts` ไม่ใช่การตรวจจับ ticker จากข้อความ ไม่ได้อ้างว่า BLS กล่าวถึงสินทรัพย์เหล่านั้น และไม่ให้สัญญาณทิศทางราคา มีลิงก์ Yahoo Finance สำหรับดูข้อมูลต้นทางโดยไม่คัดลอกข้อมูลจาก Yahoo

คำแปลเดิม 36 ประกาศยังอยู่ และไม่ถูกนำไปใช้กับต้นฉบับที่แก้ไข ข่าวใหม่หรือข่าวที่ไม่มีคำแปลแสดงภาษาอังกฤษพร้อมสถานะ
