# Langbaan Invest

เว็บภาษาไทยสำหรับค้นหาและติดตามแหล่งอ้างอิงการลงทุน 36 รายการในหมวด A–G ตามรายการที่กำหนด ใช้ Next.js, TypeScript และ Tailwind CSS

## พัฒนา

ใช้ Node.js 24 และ npm 11

```sh
npm ci --cache /tmp/langbaan-npm
npm run dev
```

## ตรวจสอบและรัน production

```sh
npm run build
npm run typecheck
npm start
```

ค้นหาด้วยชื่อ เว็บไซต์ หรือหมวดหมู่ กดดาวเพื่อบันทึกและดูรายการที่บันทึกไว้ รายการและโหมดมืดเก็บใน localStorage ของเบราว์เซอร์ โดยไม่ต้องมีบัญชีหรือ API key

รายการเป็นลิงก์ต้นทาง ไม่ใช่ข่าวสด ไม่ได้ยืนยันการเข้าถึงทุกเว็บไซต์ และยังไม่มีการดึงหรือสรุปเนื้อหาอัตโนมัติ บางแหล่งต้องสมัครสมาชิก หมวด G ระบุว่าต้องตรวจการเข้าถึง ส่วน Investor Relations รอ watchlist และ URL ทางการที่ตรวจสอบแล้ว

ขั้นต่อไปสำหรับระบบข่าวสด: เลือก RSS/API ที่อนุญาตการนำเนื้อหามาใช้ แล้วเพิ่มเวลาเผยแพร่ แหล่งที่มา และหน้าข่าว โดยไม่คัดลอกบทความเต็มโดยไม่มีสิทธิ์
